# 《第九特区》交互式设定地图

> 把伪戒的长篇小说《第九特区》，做成一张可以交互探索的「世界 · 人物 · 剧情」地图。

灾变之后、持续数十年的「冰封期」极寒末世。本项目是一个静态单页应用，把全书的世界地图、人物档案、人物关系、故事时间线与重点情节，整合成可点击、可检索、可动态演示的网页。

## ✨ 功能

- **设定地图**：全球中文版地图，点击任意据点查看场景图、简介、关联势力与关键事件。
- **崛起之路**：一键播放秦禹从无人区发家，经松江、黑街，一路到落地川府的动态轨迹。
- **人物关系**：主要/次要人物分组，配立绘头像，查看身份、性格、故事与人物关系；支持搜索与势力筛选。
- **故事时间线**：按剧情阶段梳理事件脉络。
- **重点情节**：地区争斗 / 派系争斗 / 战争残酷三阶段的名场面，并为短视频预留位置。

## 🧱 技术栈

Vite + React + TypeScript 静态 SPA，测试用 Vitest 与 Playwright。

## 🚀 本地运行

```bash
npm install
npm run dev      # 开发服务器，默认 http://localhost:5173
npm run build    # 打包到 dist/
```

## ☁️ 部署

本项目是纯静态站点（`npm run build` 产出 `dist/`），可部署到任意静态托管。需把「找不到的路径」回退到 `index.html`（SPA 路由）。

- **Vercel**：Root Directory 设为 `第九特区`，推送 `main` 自动发布。
- **国内免翻墙**：可托管到阿里云 OSS / 腾讯云 COS / CloudBase 静态托管，或国内轻量服务器 + Nginx（示例见 [`deploy/nginx.conf`](deploy/nginx.conf)）。
