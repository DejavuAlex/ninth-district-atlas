# 《第九特区》素材提示词

本目录存放用于生成配图的详细提示词，前端页面不再直接展示提示词，只展示城市与人物的介绍。

## 生成图片投放约定
- 地点场景图：生成后命名为 `<地点id>.png`，放入 `public/scenes/`。
- 人物形象图：生成后命名为 `<人物id>.png`，放入 `public/portraits/`。
- 前端会按 id 自动加载对应图片，缺失时显示占位。
