# 《第九特区》全球地图 生成提示词

## 一句话主体
一张灾变后冰封末世的「第九特区·全球地图」，俯视全景的奇幻世界地图/游戏世界地图风格，广阔幽蓝的大洋之上漂浮着被冰雪覆盖的破碎大陆与群岛。

## 中文提示词（可直接用）
俯视视角的奇幻世界地图，名为「第九特区·全球地图」；灾变之后、持续数十年冰封期的极寒末世。画面是一片广阔深邃的幽蓝色海洋，海面上漂浮着大小不一、被皑皑白雪与浮冰覆盖的破碎大陆和群岛，大陆边缘是开裂的冰盖与浮冰碎块，海陆交界处有浅青色的薄冰与冰裂纹。陆地中央透出冷褐色的山脉、丘陵与密集的微缩城镇聚落（俯视的小房屋、街区、要塞轮廓），冰原上散布河流、道路与裂谷。整体由若干被海洋分隔的板块组成，板块之间用淡淡的虚线边界与航线连接，呈现出明显的分区感。柔和的卫星俯瞰光照，低饱和冷色调（冰蓝、钢青、雪白、冷褐点缀），薄雾与寒气弥漫，氛围苍茫、辽阔、肃杀又壮美。高细节，电影级概念美术，幻想地图绘本质感。

## 区域布局参考（如生成支持文字/分区，请按此安排，自左到右、自上而下）
- 左侧：一区（大陆）、三区（偏左下的大陆）
- 中部：二区、四区、八区，以及一片片浮冰与「冰封区 / 无人区」标注
- 右侧：六区（上）、九区、七区（下），靠最右有「夏岛」小岛
- 中下与右下：五区、川府、藏源、老三角、北风口、盐岛 等据点
- 大片留白的深蓝处标注「海洋」；零散区域标注「待规划区 / 无人区」
